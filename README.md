# SpatialTrainer3D

**Spatial Trainer 3D** — интерактивное трёхмерное приложение для развития пространственного мышления, зрительного восприятия и умственных способностей с помощью взаимодействия с 3D-объектами.

Проект направлен на демонстрацию того, что технологии виртуальной и трёхмерной реальности могут использоваться не только для развлечения, но и для обучения и развития человека.

## Возможности

В текущей версии приложения реализованы:

- **Тренировка вращения фигур** — выполнение заданий на мысленное и визуальное вращение трёхмерных объектов.
- **Сопоставление фигур** — поиск соответствий между пространственными объектами.
- **Система результатов** — подсчёт набранных баллов и оценка правильности ответов.
- **Статистика** — просмотр результатов тренировок.
- **Отслеживание прогресса** — анализ результатов и изменений показателей пользователя.

## Технологии

Проект разработан с использованием:

- Python 3.14
- Ursina Engine
- Panda3D
- SQLite
- Pytest

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Ego1ST52/SpaitalTrainer3D.git
cd SpaitalTrainer3D
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация окружения

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 4. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 5. Запуск приложения

```bash
python main.py
```

## Тестирование

Для запуска автоматических тестов используется Pytest:

```bash
python -m pytest -v
```

Тесты проверяют основные компоненты приложения, включая логику вращения фигур, генерацию заданий, работу сессий, статистику и базу данных.

## Планы развития

SpatialTrainer3D продолжает развиваться. В дальнейшем планируется расширение функциональности, добавление новых тренировочных режимов и заданий, а также совершенствование пользовательского интерфейса.

## Цель проекта

Продемонстрировать возможности использования трёхмерных технологий в образовательной среде и показать, что взаимодействие с виртуальными объектами может стать эффективным инструментом развития пространственного мышления.
